## About

I build web applications and developer tooling, mostly across the TypeScript and Python ecosystems.
Recent work spans document-grounded AI chat platforms, Python runtime tracing tools published to PyPI,
and computer-vision research on text extraction from natural scene images.

- Currently studying **Computer Science Engineering** at **Vellore Institute of Technology, Andhra Pradesh**
- Working with **Next.js**, **FastAPI**, and LLM-backed application architecture
- Open to collaboration on full-stack and applied-ML projects
